# 🐱 Автоматический сбор наград в BongoCat

> ⚠️ **Дисклеймер:** Данный метод предназначен исключительно для личного использования и ознакомления с работой .NET-приложений. Использование может нарушать условия игры.

## 🔧 Инструкция по модификации

### 📥 Шаг 1: Скачивание инструментов
Скачайте актуальную версию **dnSpy** с официального репозитория GitHub:  
👉 [https://github.com/dnSpy/dnSpy/releases](https://github.com/dnSpy/dnSpy/releases)

### 📂 Шаг 2: Открытие файла сборки
1. Запустите `dnSpy.exe`.
2. Перейдите в меню **File → Open** / **Файл → Открыть**.
3. Откройте файл по следующему пути:  
   `Steam\steamapps\common\BongoCat\BongoCat_Data\Managed\Assembly-CSharp.dll`

### 🔍 Шаг 3: Навигация по коду
В левой панели Assembly Explorer разверните ветки:
```
Assembly-CSharp.dll
└── BongoCat
    └── Shop
        └── TimerUpdate()
```

### ✏️ Шаг 4: Редактирование метода
1. Кликните правой кнопкой мыши по `TimerUpdate()` в панели Assembly Explorer.
2. Выберите **Edit Method** / **Изменить Метод**.
3. В открывшемся окне с кодом найдите место, как показано на скриншоте ниже, и добавьте строку:  
   `this._shopItem.Buy();`

![Пример редактирования метода](https://github.com/RoninOnis/BongoCat-auto/blob/main/example.png)  
*(Убедитесь, что строка вставлена в правильное место внутри метода!)*

### 💾 Шаг 5: Сохранение изменений
1. Нажмите **Compile** / **Компилировать** в окне редактирования.
2. В главном меню выберите **File → Save Module** / **Файл → Сохранить модуль**.
3. Подтвердите замену оригинального файла `Assembly-CSharp.dll` → **OK**.

---

## 🔄 Важное примечание
При компилировании и модифицировании DLL игра должна быть закрыта. После каждого обновления BongoCat в Steam файл `Assembly-CSharp.dll` будет восстановлен до оригинального состояния. Вам потребуется **повторить шаги 2–5 заново**.

# 🎹 Keyboard Masher / Клавиатурный кликер

[![Python Version](https://img.shields.io/badge/python-3.x-blue.svg)](https://www.python.org/)
[![Platform](https://img.shields.io/badge/platform-Windows-lightgrey.svg)](https://www.microsoft.com/windows)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

## 📝 Описание

Keyboard Masher - это утилита для Windows, которая эмулирует одновременное нажатие всех клавиш клавиатуры с регулируемой скоростью. Программа создает случайные задержки между нажатиями для имитации естественного поведения.

### 🎯 Возможности

- ⚡ Одновременное нажатие ВСЕХ клавиш клавиатуры
- 🎲 Рандомизированные задержки между нажатиями (0.01-0.04 сек)
- ⏱️ Рандомизированная длительность нажатий (0.02-0.04 сек)
- 📊 Подсчет статистики (время работы, количество нажатий, скорость)
- 🎮 Управление через горячие клавиши
- 🔄 Работа в фоновом режиме

## 🎮 Использование

### Управление

| Клавиша | Действие |
|---------|----------|
| **TAB** | Включить/Выключить клики |
| **SHIFT** | Выйти из программы |

### Что нажимается:

| Категория | Клавиши |
|-----------|---------|
| **Буквы** | A-Z (все латинские буквы) |
| **Цифры** | 0-9 |
| **Специальные** | Enter, Esc, Backspace, Delete, Insert, Home, End, Page Up, Page Down |
| **Символы** | - = [ ] ; ' , . / \\ ` |
| **Другие** | Пробел |

### Пример работы

```
==================================================
             КЛАВИАТУРНЫЙ КЛИКЕР                 
==================================================
Управление:
  TAB   - Вкл/Выкл клики
  SHIFT - Выход из программы

Нажимаются все клавиши одновременно:
  • Буквы A-Z
  • Цифры 0-9
  • Специальные клавиши (Enter, Esc, Backspace...)
  • Символы (- = [ ] ; ' , . / \ `)
  • Пробел
==================================================
```

## ⚙️ Настройка

Вы можете изменить параметры работы в начале скрипта:

```python
# Настройки кликера
MIN_PRESS_DUR = 0.02  # Минимальное время нажатия (сек)
MAX_PRESS_DUR = 0.04  # Максимальное время нажатия
MIN_DELAY = 0.01      # Минимальная пауза между кликами
MAX_DELAY = 0.04      # Максимальная пауза
TOGGLE_HOTKEY = KEY_TAB  # Клавиша для вкл/выкл
EXIT_HOTKEY = KEY_SHIFT  # Клавиша для выхода
```

## 📊 Статистика

При выходе из программы (SHIFT или Ctrl+C) отображается статистика:

```
========================================
           СТАТИСТИКА                  
========================================
Время работы: 0ч 15м 23с
Всего нажатий: 15423
Скорость: 16.67 нажатий/сек
========================================
```

## 🛠️ Технические детали

- **Платформа:** Только Windows (использует Windows API)
- **Библиотеки:** 
  - `ctypes` - для вызова Windows API
  - `threading` - для фонового отслеживания клавиш
  - `random` - для рандомизации задержек

### Как это работает

1. Программа запускается и ожидает нажатия TAB
2. При активации начинается цикл:
   - Одновременное нажатие ВСЕХ клавиш через Windows API
   - Случайная задержка (удержание клавиш)
   - Одновременное отпускание всех клавиш
   - Пауза перед следующим циклом
3. Отдельный поток отслеживает горячие клавиши
4. Статистика собирается в реальном времени

## ⚠️ Предупреждения

- 🚫 **Не используйте** в полях ввода паролей
- 💡 Будьте осторожны в текстовых редакторах
- 🎮 Идеально подходит для тестирования или "задорного спама"
- ⏸️ Не забывайте отключать программу, когда она не нужна

## 🔧 Возможные проблемы и решения

### Если не работает:
1. Убедитесь, что используете Windows
2. Проверьте, не блокирует ли антивирус
3. Запустите от имени администратора (если нужно)

### Проблемы с кодировкой:
Скрипт автоматически настраивает UTF-8 вывод, но в редких случаях может потребоваться:
```bash
chcp 65001
python main.py
```
